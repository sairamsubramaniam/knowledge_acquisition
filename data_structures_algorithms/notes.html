RAM & Storage Structures

Source: Neetcode - DSA For Beginners: Lesson 1

  • One integer is stored in 4 bytes (32 bits)
  • One ASCII string takes 1 byte (8 bits)
  • Arrays are always stored contiguously in RAM
  • RAM also stores "addresses" corresponding to the values stored

Big O

Sources:
Algortihms & Data Structures Tutorial - FreeCodeCamp + Team Treehouse

  • TIME COMPLEXITY:

  • About "Logarithmic Time Complexity":
    • Log n to the base 2 tells us, how many times should I divide n to reach 1
    • In Binary search, you divide the input range by 2 in every iteration and therefore its time complexity is O(Log n)
  • The other types of complexity functions are: Linear O(n), Quadratic O(n^2) or Polynomial O(n^k), Quailinear O(n log n), Exponential O(x^n)
  • Examples for each:
    • Linear O(n) -
    • Logarithmic O(log n) - Binary Search
    • Quasilinear O(n log n) - Merge Sort Algorithm
    • Quadratic O(n^2) - Brute force search for finding duplicates
    • Exponential O(x^n) - Brute force search for cracking passwords / Travelling Salesman problem

  • SPACE COMPLEXITY:

  • This is NOT about how big or small the input actually is. We only care about measuring the growth of space during function runtime!

Data Structures

Sources:
Algortihms & Data Structures Tutorial - FreeCodeCamp + Team Treehouse

  • Array:
    • Usually, when you create an array, you must declare the size and type of elements stored in it.
    • And this is why arrays can be stored contiguously in RAM
    • Note that in python, lists are like arrays, but they allow any size and any type of elements. How they do it is:
      • The arrays are resized after pre-determined intervals (and not after every append)
      • Instead of storing the values in a list, python stores the references, therefore, any type of value can be added there
    • Because they are stored contiguously and valkue type is known, calculating the address of a given index is just a formula. No traversal of the array is required to fetch
    • Fetching a value from an array is therefore O(1) time complexity
    • Inserting and deleting requires O(n) and after inserting or deleting, you have to shift every single element in the array
